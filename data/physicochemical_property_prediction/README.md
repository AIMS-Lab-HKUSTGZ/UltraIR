# Physicochemical Property Prediction Data

## Sources

The task can be built independently from [NIST Chemistry WebBook](https://webbook.nist.gov/chemistry/),
[SDBS](https://sdbs.db.aist.go.jp/), or the [simulated USPTO IR
dataset](https://zenodo.org/records/16417648). Prepare each source independently;
`fold-demo` contains a small packaged example.

## Prepared arrays and target order

Keep NIST, SDBS, and USPTO in separate prepared roots. Each fold must contain:

```text
fold-<1..5>/<train|valid|test>/
  ir_norm.npy    float [N, L]
  properties.npy float [N, 11]
```

The 11 columns are generated by RDKit and must remain in this exact order:

```text
SAScore, LogP, TPSA, NumHDonors, NumHAcceptors, NumRotatableBonds,
FractionCSP3, BertzCT, QED, NumAromaticRings, NumAliphaticRings
```

Every spectrum row and property row must refer to the same molecule. Install an
RDKit distribution that provides `rdkit.Contrib.SA_Score` before running the
label generator.

## Shared molecular preparation and normalization

First convert each source to aligned `ir.npy`/`ir_norm.npy` and `smiles.npy`,
then use the common processor:

```bash
python -m data.common.molecular \
  --ir /path/to/converted/source/ir_norm.npy \
  --smiles /path/to/converted/source/smiles.npy \
  --output-dir /path/to/prepared/physicochemical_property_prediction/source \
  --k 5 --valid-fraction 0.1 --seed 42
```

`data.common.molecular` validates finite values and row alignment, performs
row-wise min-max normalization of every IR spectrum to `[0, 1]`, computes the
11 RDKit properties, removes invalid SMILES by default, and writes five
scaffold-aware approximately 70/10/20 folds. It also writes a manifest and
other shared labels; the downstream task uses `properties.npy`.

### NIST WebBook

Use only an explicit ID list. The complete conversion is:

```bash
python -m data.common.nist_download \
  --ids /path/to/nist_ids.txt --output-dir /path/to/work/nist/jdx
python -m data.common.pubchem jcamp \
  --input-dir /path/to/work/nist/jdx \
  --output-dir /path/to/work/nist/smiles_txt
python -m data.common.jcamp \
  --input-dir /path/to/work/nist/jdx \
  --smiles-dir /path/to/work/nist/smiles_txt \
  --output-dir /path/to/work/nist/converted
python -m data.common.molecular \
  --ir /path/to/work/nist/converted/ir_norm.npy \
  --smiles /path/to/work/nist/converted/smiles.npy \
  --output-dir /path/to/prepared/physicochemical_property_prediction/nist
```

The JCAMP converter uses 400-4000 cm-1 and 3600 points, then applies the common
normalization contract. The downloader writes a request manifest.

### SDBS PNG spectra

Provide a local SDBS metadata CSV and its PNG files. Enrich the CSV, digitize the
PNGs, and pass the aligned arrays to `molecular`:

```bash
python -m data.common.pubchem csv \
  --input-csv /path/to/sdbs/metadata.csv \
  --output-csv /path/to/work/sdbs/metadata_with_smiles.csv
python -m data.common.sdbs_image \
  --metadata-csv /path/to/work/sdbs/metadata_with_smiles.csv \
  --image-root /path/to/sdbs \
  --smiles-field SMILES --skip-invalid \
  --output-dir /path/to/work/sdbs/converted
python -m data.common.molecular \
  --ir /path/to/work/sdbs/converted/ir.npy \
  --smiles /path/to/work/sdbs/converted/smiles.npy \
  --output-dir /path/to/prepared/physicochemical_property_prediction/sdbs
```

The PNG converter calibrates the SDBS two-scale axis and records rejected rows.
PubChem enrichment is a separate, rate-limited step.

### USPTO Parquet spectra

For the local simulated USPTO Parquet release:

```bash
python -m data.common.parquet_ir \
  --input-dir /path/to/uspto/parquet \
  --output-dir /path/to/work/uspto/converted
python -m data.common.molecular \
  --ir /path/to/work/uspto/converted/ir_norm.npy \
  --smiles /path/to/work/uspto/converted/smiles.npy \
  --output-dir /path/to/prepared/physicochemical_property_prediction/uspto
```

`parquet_ir` requires `pyarrow`, validates the spectrum columns, interpolates
400-4000 cm-1 to 3600 points, and writes an already normalized IR array. The
common molecular step still performs final validation, label generation, and
fold creation.

## Target normalization and run commands

IR normalization is performed offline by `molecular.py`. Property targets are
stored in their original scale; the YAML task standardizes each property using
the selected training fold. The loader resizes spectra to 1792 points at
runtime.

Run the included example or a prepared NIST root as follows:

```bash
python -m scripts.run \
  --config configs/physicochemical_property_prediction/nist.yaml \
  --fold demo

python -m scripts.run \
  --config configs/physicochemical_property_prediction/nist.yaml \
  --data-root /path/to/prepared/physicochemical_property_prediction/nist \
  --fold 1

python -m scripts.run \
  --config configs/physicochemical_property_prediction/nist.yaml \
  --data-root /path/to/prepared/physicochemical_property_prediction/nist \
  --kfold
```

Use the corresponding `sdbs.yaml` or `uspto.yaml` for those sources. Explicit
`--config` is required when selecting among the three dataset YAML files.
