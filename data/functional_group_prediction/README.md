# Functional Group Prediction Data

## Sources

This task supports three independent molecular sources:

- [NIST Chemistry WebBook](https://webbook.nist.gov/chemistry/)
- [SDBS](https://sdbs.db.aist.go.jp/)
- [Simulated USPTO IR dataset](https://zenodo.org/records/16417648)

Prepare any of these sources independently. `fold-demo` contains a small
packaged example.

## Prepared arrays and label order

Prepare each source in its own root. Every fold must contain:

```text
fold-<1..5>/<train|valid|test>/
  ir_norm.npy             float [N, L]
  functional_groups.npy   uint8/binary [N, 17]
```

The rows are molecular records and must remain aligned. The 17 columns are
generated by RDKit in this fixed order:

```text
Alkane, Methyl, Alkene, Alkyne, Alcohols, Amines, Nitriles, Aromatics,
Alkyl halides, Esters, Ketones, Aldehydes, Carboxylic acids, Ether,
Acyl halides, Amides, Nitro
```

## Shared molecular preparation

All three sources should converge to `ir.npy` (or `ir_norm.npy`) and an aligned
`smiles.npy`, then use the same public processor. It validates finite spectra,
normalizes each spectrum row-wise to `[0, 1]`, computes the RDKit functional
groups (and the other molecular labels used by sibling tasks), filters invalid
SMILES by default, and writes five scaffold-aware folds:

```bash
python -m data.common.molecular \
  --ir data/converted/source/ir_norm.npy \
  --smiles data/converted/source/smiles.npy \
  --output-dir data/prepared/functional_group_prediction/source \
  --k 5 --valid-fraction 0.1 --seed 42
```

The output includes `manifest.json`, the full arrays, and `fold-1` through
`fold-5`. Invalid SMILES and their aligned spectra are removed together, and
the manifest records the row counts.

The converters and their expected inputs are:

### NIST WebBook

Supply an explicit one-ID-per-line file to the NIST downloader:

```bash
python -m data.common.nist_download \
  --ids runs/nist_ids.txt \
  --output-dir data/work/nist/jdx
python -m data.common.pubchem jcamp \
  --input-dir data/work/nist/jdx \
  --output-dir data/work/nist/smiles_txt
python -m data.common.jcamp \
  --input-dir data/work/nist/jdx \
  --smiles-dir data/work/nist/smiles_txt \
  --output-dir data/work/nist/converted
python -m data.common.molecular \
  --ir data/work/nist/converted/ir_norm.npy \
  --smiles data/work/nist/converted/smiles.npy \
  --output-dir data/prepared/functional_group_prediction/nist
```

`nist_download` writes a request manifest and failed-ID list. `jcamp` parses
uncompressed JCAMP-DX, interpolates the 400-4000 cm-1 range to 3600 points, and
performs the initial row-wise normalization. The final molecular step repeats
the same contract and creates the labels and folds.

### SDBS

Provide a local SDBS metadata CSV and its PNG files. The CSV must contain
`Image File`, `SDBS No`, and a CAS column (normally `CAS No`):

```bash
python -m data.common.pubchem csv \
  --input-csv data/sdbs/metadata.csv \
  --output-csv data/work/sdbs/metadata_with_smiles.csv
python -m data.common.sdbs_image \
  --metadata-csv data/work/sdbs/metadata_with_smiles.csv \
  --image-root runs/sdbs \
  --smiles-field SMILES --skip-invalid \
  --output-dir data/work/sdbs/converted
python -m data.common.molecular \
  --ir data/work/sdbs/converted/ir.npy \
  --smiles data/work/sdbs/converted/smiles.npy \
  --output-dir data/prepared/functional_group_prediction/sdbs
```

`pubchem csv` preserves input-row order and adds a status column. The PNG
converter calibrates the SDBS two-scale axis, writes 3600-point transmittance
traces, and records rejected rows. The subsequent molecular step supplies the
common `[0, 1]` normalization and RDKit labels.

### USPTO Parquet

For the simulated USPTO release, place the local Parquet files in one directory
and run:

```bash
python -m data.common.parquet_ir \
  --input-dir runs/uspto/parquet \
  --output-dir data/work/uspto/converted
python -m data.common.molecular \
  --ir data/work/uspto/converted/ir_norm.npy \
  --smiles data/work/uspto/converted/smiles.npy \
  --output-dir data/prepared/functional_group_prediction/uspto
```

`parquet_ir` requires `pyarrow`, expects ID/SMILES/frequency/spectrum columns,
interpolates 400-4000 cm-1 to 3600 points, and performs row-wise min-max
normalization. The molecular step validates and labels every resulting row.

## Run and cross-validation

The included example can be run with the NIST config. Use the matching
dataset config for a full prepared root:

```bash
python -m scripts.run \
  --output-dir runs/functional-group-prediction \
  --config configs/functional_group_prediction/nist.yaml \
  --fold demo

python -m scripts.run \
  --output-dir runs/functional-group-prediction \
  --config configs/functional_group_prediction/nist.yaml \
  --data-root data/prepared/functional_group_prediction/nist \
  --fold 1

python -m scripts.run \
  --output-dir runs/functional-group-prediction \
  --config configs/functional_group_prediction/nist.yaml \
  --data-root data/prepared/functional_group_prediction/nist \
  --kfold
```

Replace `nist.yaml` and the root with `sdbs.yaml` or `uspto.yaml` as needed.
Because there are multiple dataset YAML files, use `--config` rather than an
ambiguous task abbreviation.
